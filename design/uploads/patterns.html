03 Data masking
Sensitive values render blurred by default. The privacy posture is on, not opt-in.
412,880.20
masked (default)
412,880.20
revealed

Wrap any sensitive value in <span class="mask">. While body.masked is set, those spans get a 6px blur, are un-selectable, and ignore pointer events — so a shoulder-surfer or a screen-share leaks nothing. Reveal is a deliberate, audited gesture, not a hover.

Do
  • Mask names, amounts, wallet addresses, contact details by default.
  • Keep IDs, types, statuses and dates visible — they’re needed to navigate.
Don’t
  • Reveal on hover — masking must survive a screenshot.
  • Mask structure (column heads, labels) — only the values.

05 Alert routing
Work arrives as a banner, not a notification center. The system points the clerk at the next thing.
Slack · #recon-alertsWhitepay processed a new settlement — its working terms aren’t on file yet. Open provider →

An inbound event from processing posts to #recon-alerts and surfaces as a banner at the top of the register. The jump link deep-routes straight to the flagged record in edit mode — closing the loop from “something happened” to “fill the values” in one click. There is no separate inbox to triage.
